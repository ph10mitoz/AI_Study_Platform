# AI Study Platform

Plataforma pessoal pra guiar estudo de IA, busca de oportunidades (bolsas, intercâmbios, pesquisa) e curadoria de notícias relevantes na área — um produto único, construído aos poucos, frente por frente.

## As três frentes

| Frente | Status | O quê |
|---|---|---|
| [`estudo/`](estudo/) | em construção | trilha de matemática/ML do zero (NumPy → PyTorch → ferramentas de produção/agentes), com ciclo ensinar → projeto prático → comparação com IA → flashcards (SM-2) |
| [`oportunidades/`](oportunidades/) | ideação | coletânea curada de bolsas/intercâmbios/programas em ML/DL/AI, adaptada ao perfil e ao estágio de estudo atual |
| [`noticias/`](noticias/) | ideação | curadoria (resumo + link) de fontes/labs específicos seguidos, ligada ao estágio de estudo atual |

As três compartilham um contexto central (perfil, estágio atual, progresso) — ver `CLAUDE.md` pra como isso se conecta.
